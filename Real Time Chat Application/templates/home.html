Real-Time Messaging Powered by Python & Django Channels

A complete, full-stack real-time communication platform built using Django, Django Channels, WebSockets, and SQLite. Experience zero-latency messaging, private chats, group channels, file attachments, and live presence.

Create Free Account Sign In to Chat

WebSockets & Channels

Messages are delivered instantaneously using asynchronous ASGI WebSocket connections managed through Django Channels consumers.

1-on-1 & Group Chats

Start private end-to-end conversations with any registered student or colleague, or create group chat rooms with multiple participants.

SQLite Database

All messages, attachments, user profiles, and group memberships are fully normalized and stored in SQLite, easily inspectable via DB Browser.

File & Image Sharing

Exchange images, screenshots, PDFs, and documents directly inside private or group chat streams with instant live previews.

Online Presence & Typing

Track real-time active user status indicators and live typing notifications as users compose responses.

Modern Dual Themes

Enjoy a beautiful responsive interface crafted with Bootstrap 5 and custom CSS with seamless Light and Dark mode toggle.

Architecture & Tech Stack

Backend: Python 3, Django, Django Channels, Daphne | Database: SQLite (db.sqlite3) | Frontend: Bootstrap 5, Vanilla JS WebSockets, CSS3
